## 🌟 Overview

**SyncBubbles** transforms how traders discover and copy alpha. Instead of noisy group chats and fragmented call channels, SyncBubbles pairs real-time charts with live social conviction. Every trade is a public thesis, every win-rate is on-chain verifiable, and users can copy top KOLs in a single tap with automated Take-Profit and Stop-Loss limits.

---

## 🚀 Key Features

* **⚡ 1-Tap Copy Trading**: Instantly mirror the buy and sell orders of top-performing traders directly into your Solana wallet.
* **🛡️ Automated TP/SL & Trailing Limits**: Safeguard capital with customizable take-profit ladders, stop-loss triggers, and trailing stops configured before you enter.
* **🌐 Live Bubble Cloud Visualization**: High-conviction visual interface clustering top traders and trending tokens by market volume, momentum, and win-rate.
* **💬 Integrated Alpha Theses**: Trades aren't just transactions; they are ideas. Every trade includes the trader's entry rationale and real-time community engagement.
* **🔒 Non-Custodial & Secure**: Wallets remain completely user-owned via secure Privy integration and encrypted client-side transaction signing.
* **📈 The Trenches**: Real-time scanner for newly bonded curve coins, whale entries, and rapid momentum breakouts.

## 🛠️ Local Development & Deployment

### Run Locally

```bash
# Clone the repository
git clone https://github.com/WerelayAgent/syncbubbles.git
cd syncbubbles

# Install dependencies (or run directly with serve)
npx serve -s . -l 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Deploy to Vercel

```bash
vercel --prod
```

Pre-configured with [vercel.json](file:///vercel.json) rewrite rules for SPA clean routing across `/app`, `/privacy`, and `/terms`.
